# Политика конфиденциальности FORMETR

Дата редакции: 19 октября 2026 года.

## Кто обрабатывает данные

Владелец FORMETR. Контакт для вопросов и запросов: Kopytovdv1999@gmail.com.

## Какие данные использует бот

FORMETR сохраняет Telegram ID и имя пользователя, ответы фитнес-анкеты, физические параметры, выбранные цели, пищевые ограничения, планы тренировок, замеры и историю прогресса. Telegram самостоятельно обрабатывает данные аккаунта и сведения о платежах по своим правилам.

## Зачем нужны данные

Данные используются для расчёта ориентировочных целей питания, составления планов, сохранения прогресса, управления доступом и поддержки пользователя. Бот не использует данные для рекламы и не продаёт их третьим лицам.

## Оплата

Оплата цифрового доступа проводится через Telegram Stars. FORMETR получает технические сведения, необходимые для подтверждения доступа, но не получает данные банковской карты.

## Хранение и удаление

Данные хранятся в базе FORMETR, пока пользователь пользуется сервисом или пока они необходимы для работы доступа и учёта платежей. Запросить удаление данных можно по адресу Kopytovdv1999@gmail.com. Отдельные сведения о платеже могут храниться дольше, если это необходимо для разрешения споров и выполнения обязательных требований.

## Безопасность

Доступ к базе и токену бота ограничивается владельцем сервиса и средствами хостинга. Передавать в бот пароли, документы, банковские данные и подробные медицинские документы не следует.

## Возраст и здоровье

FORMETR не является медицинским сервисом. Для несовершеннолетних и ответов с медицинскими рисками обычный алгоритм изменения веса ограничивается. При вопросах о здоровье следует обратиться к квалифицированному специалисту.

## Изменения

При существенном изменении обработки данных новая редакция будет опубликована до её применения.
